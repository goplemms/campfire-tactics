# 04 · Jobs, growth & prestige — a mini-atlas

The **character build axis** — where a unit stops being a stat block and becomes *a character
the player made*. It's the deepest system in the game, so it gets its own set of pages instead of
one crowded diagram. This index is the map; each page below drills one facet.

> **Build status.** The **substrate** is largely built (primary + held jobs, per-job levels, the
> grant/predicate seam, the action-registration registry, presence/faucet). **Only the Scout →
> {Assassin · Thief} fork is a *built* prestige**; every other fork is *reserved / designed-not-
> built*, and the FFT ability-borrowing **projection** into loadout slots is "a later pass." These
> diagrams map the **framework** (D65); per-class *content* lands one pass at a time.

## The one-paragraph version

Growth runs on **two orthogonal axes**: **breadth** (hold & mix more jobs — rides *character* level
→ loadout slots; a new job **adds** kit) and **depth** (grow one job deep — rides *job* level →
**Prestige**; a successor **replaces** kit in place). Both **acquiring a job** and **triggering a
prestige** run through **one seam** — a predicate guarding an effect — and jobs arrive **through
play**, not a menu, which is what makes a unit feel *yours*. The whole tree is **symmetric**:
available to mercenaries and the authored cast alike; power attaches to **story**, not tier.

## The roster at a glance

| Group | Jobs | Kit shape |
|---|---|---|
| **Combat** | Soldier · Heavy Knight · Hunter · Medic · Snare-Trapper · Scout | 1–2 active + 1 passive (identity anchor) |
| **Non-combat / support** | Survivalist · Cook · Merchant · Noble · Banker | 1 presence-anchor + 1–2 verbs |
| **Prestige forks** | **Scout → {Assassin · Thief}** *(built)* · all others *reserved* | a **diff** on the base kit |
